# Материалы дизайна для репозитория WheelTalk

Три готовые задачи, переданные из проекта дизайна. Распаковать в корень репозитория:
**`C:\Work\repos\WheelTalk\`** — так, чтобы получились `WheelTalk\handoff-tiles\`,
`WheelTalk\handoff-quicksheet\` и `WheelTalk\handoff-settings\`. В индекс не добавлять: это
материалы, а не код.

| Папка | Задача | С чего начать |
|---|---|---|
| `handoff-tiles` | Экран «Цифры»: плитка двух форм и подбор кегля | `task-tiles.md` |
| `handoff-quicksheet` | Нижняя шторка: разделы, читаемость, свои значки | `task-quicksheet.md` |
| `handoff-settings` | Показ и правка настроек | `task-settings.md` |

В каждой папке: `task-*.md` (задача — читать первой), `plan-*.md` (требования), `*-mockup.dc.html`
(макет, открывается двойным щелчком) и `support.js` — служебный файл, нужный только чтобы макет
открылся.

Задачи независимы, порядок любой, общих файлов приложения у них нет. Единственное пересечение —
`AppStrings.resx`: новые ключи добавляют все три, поэтому делать их лучше по одной, а не тремя
ветками сразу.

Кириллица в именах заменена латиницей: она мешала сборке архива.
