# План 22. Инсет верхних уведомлений и управляемый реплей для агентских прогонов

> **Статус: черновик, не начат** — записан со слов владельца 02.08.2026, по скриншоту с
> эмулятора. **Ветка:** `android`. Оба пункта малые; §2 стоит сделать до следующего большого
> агентского прогона на эмуляторе — он удешевляет все последующие.

## 1. Уведомления у верхней кромки — под системной строкой

**Симптом (скриншот 02.08.2026, реплей на эмуляторе):** полоса тревоги колеса
(«Unknown Alert 482.00 …») прижата к самому верху, и системные часы со значками лежат прямо на
её тексте — первая строка не читается.

**Причина.** Edge-to-edge отдаёт верхний инсет **панели** (`MainActivity` → `PanelChrome.TopInset`
→ тень и отступ канвы), а `AlertStrip` — первый ребёнок колонки `MainScreenView` с собственным
паддингом 2 dp (`AlertStrip.cs:28`) и про инсет не знает: появляясь, она встаёт под статус-бар.

**Правка.** Полоса, когда видима, добирает верхний паддинг на высоту инсета: `MainScreenView`
уже собирает экран и может отдать инсет полосе тем же путём, каким `MainActivity` отдаёт его
панели (значение у активности уже есть — `_topInsetPx`). Правило владельца — **общее**: любой
элемент, прижатый к верхней кромке, обязан компенсировать системную строку; сейчас таких два —
полоса тревоги и панель, панель уже умеет.

Проверка — на стенде: `LabSettings.WheelAlarm` включает полосу, «Панель под системной строкой»
даёт ненулевой инсет; скриншот до/после.

**Смежный записанный долг** ([handover](handover.md), хвост): полоса задумана накладкой поверх
панели, а не членом разметки, сдвигающим её вниз. Решается отдельно; паддинг-правка ему не
мешает и не отменяет его.

## 2. Управляемый реплей: команды вместо свайпов по таймеру

**Симптом.** Агентские проверки на эмуляторе водят приложение «руками» — `adb shell input
swipe/tap` по координатам и таймингу. Это хронически промахивается: шторка сама закрывается
через 5 секунд (ловушка уже записана в handover), между командами adb проходит больше, чем ждёт
UI, координаты плывут между конфигурациями, а при двух подключённых устройствах касание может
уйти не туда. Каждый промах — потерянный прогон и повторная сборка вывода.

**Сделано сразу (02.08.2026): пуск — по тапу на плашку.** Плашка «Запись готова» и так стоит на
переднем плане, когда реплей готов, — решение владельца: действие сидит прямо на ней
(`OnLinkBadgeTapped` при `IsReplay` зовёт тот же путь, что кнопка «Пуск»; текст плашки сменён на
«нажмите для пуска»). Это закрывает самый частый промах — свайп шторки ради одной кнопки — и
для человека, и для агента: плашка — крупная цель со стабильным местом.

**Остаётся сделать: командный вход без касаний** — для «стоп», экранов и всего, где цель не
плашка. `MainActivity` уже `LaunchMode.SingleTop` — обрабатывать extras в `OnNewIntent`, когда
`_transport.IsReplay`:

```
adb shell am start -n com.wheeltalk.droid/.Main.MainActivity --es replay start
adb shell am start -n com.wheeltalk.droid/.Main.MainActivity --es replay stop
adb shell am start -n com.wheeltalk.droid/.Main.MainActivity --es open rides|data|settings|sheet
```

- `replay start|stop` дергают тот же `ReplayToggleAsync`, что кнопка шторки, — никакой второй
  логики, только вход.
- `open …` зовёт `OpenScreen`/`Sheet.Toggle` — то, что сейчас достаётся свайпами.
- Ветка регистрируется **только при реплей-транспорте** (`ITransport.IsReplay`): на живом колесе
  внешнего входа не существует — не спрятан, а не создан, тем же правилом, что кнопка «Пуск»
  в шторке.
- Стенд (`WheelTalk.Lab.Droid`) при необходимости получает такой же вход отдельным шагом —
  сценарий/позиция/вариант панели; решить по факту первого промаха, не впрок.

После реализации — врезка в AGENTS.md («Как гонять приложение без колеса»): агентам пользоваться
командами, `input swipe/tap` оставить для проверки самих жестов.

## Проверка

По правилу ограничения циклов: §1 — компиляция + один прогон стенда с двумя скриншотами
(полоса при нулевом и ненулевом инсете); §2 — компиляция + один прогон на эмуляторе, где весь
сценарий (пуск реплея, шторка, «Поездки», стоп) пройден командами без единого касания. Publish
не делается.
