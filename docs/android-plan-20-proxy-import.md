# План 20. Импорт логики подключения через посредника — для всех семейств колёс

> ## ✅ ВЫПОЛНЕН ЦЕЛИКОМ — 02.08.2026
> **Ветка:** `android`. Восемь отпечатков посредника (§1, `ProxyProfiles.cs`) и второй проход
> `WheelDetector.Detect` (§2) перенесены дословно; метка `ffa8` (Begode) добавлена отдельным
> коммитом поверх копии (§6). Проверка — только тестами (§5): `ProxyProfilesTests` по всем восьми
> записям оригинала (деревья из JSON, не из нашей копии), перекрёстный тест колесо/посредник, тест
> на дубликат/фикс `ffa8`, плюс два случая в `WheelDetectionSessionTests`. 237 тестов зелёные.
> **На живом устройстве не проверялось и проверить нечем** — устройства-посредника нет ни в каком
> виде, гейт «подключились и увидели телеметрию» недостижим в принципе (см. §5). Оговорка о
> подтверждении команд через посредника — [quick-commands-design.md](quick-commands-design.md) §5.
>
> **Решение владельца 01.08.2026: железки нет и отпечатка с неё не будет; логика подключения
> копируется у оригинала один в один, для всех моделей колёс сразу.** Проверить на устройстве
> нечем, и точная копия — единственная защита от собственной ошибки: любое расхождение с
> оригиналом заведомо наше и видно в diff.
>
> **Предпосылки:** схема со стороны телефона — [proxy-devices.md](proxy-devices.md); что при этом
> делает сама железка — [proxy-device-firmware.md](proxy-device-firmware.md); опознание по дереву
> GATT уже работает и покрыто тестами (`WheelTalk.Core/Detection/`).
>
> **Цена:** восемь записей данных и один цикл в детекторе. Полвечера с тестами — и это **весь**
> объём для всех шести семейств, см. §3.
